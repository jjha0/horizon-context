앞 문장의 문맥도 참고할 수 있도록 추가 학습. 현재 번역할 문장과 같은 문서의 앞선 영어 문장을 함께 입력하도록 데이터와 프롬프트를 구성하고, 기존 LoRA 가중치를 이어서 학습함.

문맥이 포함된 번역 예시와 일반 번역 예시를 섞어서 학습했고, 여러 학습 결과를 비교한 뒤 Replay 모델을 최종 선택함. 기존 용어집 규칙도 함께 적용했으며, 번역이 비어 있거나 같은 내용이 반복되는 등 이상 출력이 생기면 한 번 다시 생성하도록 처리함.

최종 평가에서는 전체 Test 데이터 2,130개 중 무작위로 추출한 256개 문장을 사용. 3단계 모델과 비교한 결과, chrF는 36.14에서 37.00으로, BLEU는 27.21에서 27.97로 향상. 앞 문맥이 있는 192개 문장에서도 chrF가 35.25에서 36.21.
