# 문맥 인식 기반 학술 영한 번역

**기존 전문용어 특화 번역 모델에 문장 간 문맥을 반영하는 추가 파인튜닝**

`Hy-MT2-7B` · `LoRA` · `Context-aware Translation` · `Replay Training`

---

## 한눈에 보기

| 원본 데이터 | 문장·구간 데이터 | 주요 Replay 학습 | 최종 비교 평가 |
|:---:|:---:|:---:|:---:|
| **6,216**개 초록 쌍 | **21,866**개 예시 | **4,096**개 예시 | **256**개 Test 예시 |

> **핵심 아이디어**  
> 기존에는 현재 문장 자체를 번역했다면, 이번 단계에서는 **이전 영어 문맥을 함께 입력하고 현재 문장만 한국어로 번역**하도록 학습하였다.

## 01. 개선 목표

앞선 단계에서 컴퓨터공학 분야의 전문용어를 학습한 Hy-MT2-7B 기반 모델을 전달받았다. 이번 단계는 모델을 처음부터 다시 학습하는 대신, **문장 간 연결 정보를 활용하는 번역 능력**을 추가하는 데 초점을 맞췄다.

| 구분 | 입력 | 출력 |
|---|---|---|
| 기존 방식 | 현재 영어 문장 | 현재 문장의 한국어 번역 |
| 문맥 인식 방식 | **이전 영어 문맥 + 현재 영어 문장** | **현재 문장의 한국어 번역** |

문맥으로 제공한 이전 문장은 번역 결과에 함께 출력하도록 요구하지 않았다.

## 02. 데이터 가공

KCI 학술 논문의 **초록 단위 영한 병렬 데이터**를 문장·구간 단위로 분리하고 영어·한국어 대응 구간을 구성하였다. 원래 논문 단위의 Train / Validation / Test 분할은 유지하였다.

| 분할 | 원본 초록 쌍 | 문장·구간 단위 예시 |
|:---|---:|---:|
| Train | 4,972 | 17,579 |
| Validation | 620 | 2,157 |
| Test | 624 | 2,130 |
| **합계** | **6,216** | **21,866** |

**수량을 해석할 때 주의할 점**

- 초록 쌍 6,216개와 문장·구간 예시 21,866개는 **집계 단위가 다르다**.
- `Train 17,579개`는 학습에 사용할 수 있도록 구성한 데이터 풀이며, **최종 Replay 학습에 모두 투입했다는 의미는 아니다**.
- 자동 정렬 과정에는 1:1뿐 아니라 복수 문장이 하나의 구간으로 묶인 사례도 있으므로, 모든 예시를 단일 문장 쌍으로 간주할 수는 없다.
- 자동 정렬된 한국어 정답은 전문 번역가가 전수 검증한 골드 데이터가 아니다.

### 데이터에서 모델까지

**데이터 준비:**  
`KCI 영·한 초록 6,216쌍` → `문장 분리·정렬` → `문장·구간 예시 21,866개`

**학습 및 평가:**  
`Train 17,579개` → `Replay 학습 예시 4,096개 선별` → `기존 전문용어 LoRA 추가 학습` → `Test 256개 비교`

Replay 학습 예시 4,096개는 **문맥 번역 3,072개와 일반 번역 1,024개**로 구성하였다.

## 03. 학습 진행

초기 문맥 학습 이후 검증 성능이 일관되게 향상되지 않는 문제를 확인하였다. 이에 따라 문맥 입력만 반복 학습시키기보다, 기존 번역 능력을 함께 유지하도록 **Replay 학습**을 적용하였다.

### Replay 데이터 구성

| 학습 유형 | 개수 | 비율 | 입력 형태 |
|:---|---:|---:|---|
| **Context** | 3,072 | **75%** | 이전 영어 문맥 + 현재 영어 문장 |
| **Plain** | 1,024 | **25%** | 현재 영어 문장 |
| **합계** | **4,096** | **100%** | 정답은 현재 문장의 한국어 번역 |

실험은 `experiment_01` → `continue_01` → `replay_01` → 후속 Replay 추가 학습 순서로 진행하였다. 단순히 마지막 체크포인트를 사용하는 대신, 검증 데이터의 **chrF와 출력 안정성**을 함께 확인하여 모델을 선택하였다.

조건부 출력 복구 정책을 적용하여 빈 번역문, 생성 길이 제한 도달, 비정상 출력 등에 대응하였다. 이 정책이 적용된 성능과 원본 추론 성능은 구분해 해석해야 한다.

## 04. 번역 성능 개선

기존 **3단계 전문용어 모델**과 최종 **4단계 문맥·Replay 모델**을 *동일한 문장 단위 Test 샘플 256개*에서 비교하였다. 이 중 192개에는 이전 영어 문맥이 존재한다.

체크포인트 선택은 Validation 데이터의 chrF 및 출력 안정성을 기준으로 수행하였으며, Test 샘플은 최종 모델 비교에 사용하였다.

| 평가 지표 | 3단계 모델 | 4단계 모델 | 차이 |
|:---|---:|---:|---:|
| BLEU (ko-mecab) | 27.2117 | **27.9687** | **+0.7570** |
| chrF | 36.1412 | **36.9953** | **+0.8541** |
| 문맥 보유 샘플 chrF (192개) | 35.2506 | **36.2079** | **+0.9573** |

**결과 요약:** 해당 고정 테스트 표본에서 문맥·Replay 추가 학습 모델이 BLEU와 chrF 모두 더 높은 점수를 기록하였다. 주요 출력 이상은 최종 평가에서 관찰되지 않았다.

> **해석 범위**  
> 이 비교에는 추가 파인튜닝 및 Replay의 영향도 함께 포함된다. 따라서 향상을 **문맥 입력만의 효과**로 단정할 수는 없다. 또한 앞선 단계에서 보고한 *초록 단위 624개 평가 결과*와 이번 *문장 단위 256개 평가 결과*는 직접 비교하지 않는다.

## 05. 남은 과제

- **데이터 품질:** 자동 정렬된 일부 영한 문장·구간에는 의미 불일치가 남아 있을 수 있다.
- **문맥 범위:** 인접 문장 중심의 짧은 문맥을 활용하므로 논문 전체의 장거리 일관성은 검증되지 않았다.
- **평가 범위:** 총 Test 2,130개 중 256개만 최종 비교에 사용하였다.
- **전문용어 검증:** BLEU·chrF 상승만으로 전문용어의 의미 보존이 완전히 입증되지는 않는다.
- **후속 실험:** 문맥 입력 유무만 변경하는 통제 실험, 전문용어 일관성 평가, 평가셋 확대가 필요하다.

<strong>포스터용 요약 </strong>

KCI 학술 초록 6,216쌍을 기반으로 21,866개의 문장·구간 단위 영한 번역 예시를 구성하였다. 기존 전문용어 특화 Hy-MT2-7B 모델에 이전 문맥을 활용하는 추가 파인튜닝을 적용했으며, 주요 Replay 학습은 문맥 번역 3,072개와 일반 번역 1,024개를 혼합하여 수행하였다. 동일한 문장 단위 Test 샘플 256개에서 BLEU는 27.21에서 27.97로, chrF는 36.14에서 37.00으로 상승하였다. 이 결과는 해당 평가 표본에서 문맥·Replay 추가 학습 모델의 번역 점수 향상 가능성을 보여주지만, 문맥 입력의 독립적인 기여는 후속 통제 실험이 필요하다.
